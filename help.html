Navigate, inspect and edit your building

TRIPT XR adapts its navigation input to your device. Desktop keyboard and mouse controls and touch controls use the same camera movement behavior. Walk Mode remains a separate first-person experience.

2. Developer Studio — Camera and editing

The editor uses free-fly navigation. On desktop, right-drag looks around; on touch devices, enable Navigation to reveal the joystick and dedicated look area. Turn Navigation off before tapping the model to edit it.

Material picking

  1. Open the Render tab and find the Material section.
  2. Activate the Pick Material button.
  3. On touch devices, make sure touch Navigation is off.
  4. Click or tap a surface in the model. If the material can be mapped to the material catalog, its controls load in the editor.
  5. Adjust the available properties and use the existing Apply control to preview the override.

Place a 360° viewpoint

  1. Open the 360° Viewpoint tab.
  2. Activate Place viewpoint.
  3. On touch devices, make sure touch Navigation is off.
  4. Click or tap a valid surface in the model. The placement tool uses surface checks, so walls or unsuitable faces may be rejected.
  5. Complete the viewpoint details and save using the available panel controls.

Editing safety: The same viewport tap must not both rotate the camera and pick a material or place a viewpoint. In touch Navigation mode, model taps are reserved for navigation; exit it before editing.

3. Walk Mode — First-person exploration

Walk Mode is separate from Orbit / Explore and from the editor's free-fly camera. It is intended for moving through the building at a human-scale viewpoint.

4. Common procedures

Open and inspect a model
  1. Open the Main Viewer or Developer Studio.
  2. Use Open GLB or Upload GLB and choose a supported .glb file.
  3. Wait for loading to finish, then use Reset view if needed.
  4. Use Orbit / Explore controls to inspect the exterior, or enter Walk Mode for first-person exploration.
Create or view a saved section
  1. In Developer Studio, open Section Tool.
  2. Choose a cut axis and visible side, then adjust the cut position.
  3. Preview the section and save it with a descriptive name. Exposed cut surfaces are filled black for architectural section readability.
  4. In the Main Viewer, use the Section selector to load a saved section or Clear section to remove both clipping and the black cut fill.
Use the 360° viewpoints
  1. In Developer Studio, open 360° Viewpoint and place viewpoints on valid model surfaces.
  2. Save the viewpoint data using the available controls.
  3. In the Main Viewer, open 360° Views and select a viewpoint to enter the panorama.
  4. Use the panorama viewer's on-screen back control to return to the model.
Change a material
  1. Open Developer Studio and load a model.
  2. Open Render and activate Pick Material.
  3. Select a surface in the viewport.
  4. Change supported material settings, then apply the override.
  5. Use the existing reset option to remove the selected override if required.

5. Troubleshooting

WASD does not move the camera
Click the 3D viewport first if required. Check that a text field, select menu or button is not focused. On touch devices, use the on-screen joystick instead.
Camera keeps moving after releasing input
Release the keys or joystick, click outside text inputs, and return focus to the viewer. The application clears held input when the window loses focus.
Cannot pick a material or place a viewpoint on touch
Turn off the editor's touch Navigation mode first, then activate the intended editing tool. Material picking must be explicitly activated with Pick Material.
A panorama point is rejected
Try a visible floor or other supported upward-facing surface. Some walls, steep faces, or surfaces hidden by section clipping are intentionally rejected.
The model is missing or fails to load
Use a local development server, check the browser console and confirm that the GLB file is valid. Do not open module-based pages directly as file://.
